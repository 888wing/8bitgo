# 遊戲設計總覽

> 建立在 [01 Core Loop](01-core-loop.md) 的推薦方案（懷疑 × 五票即決）之上。所有數值都是起始建議，要靠原型調整。

## 1. 概念

| | |
|---|---|
| 類型 | 劇情主導的裁決模擬（法庭版 *Papers, Please*） |
| 玩家 | 七人陪審團的其中一席；第一周目是第七席 |
| 一天 | 白天在法庭聽證、評議；晚上回自家當舖站櫃台 |
| 一局 | 一場審判：五個庭審日加最終評議，約 90 分鐘；提早裁決的話，15 分鐘內就會結束 |
| 重玩 | 多結局 × 七個席位的路線 |
| 美術 | 8-bit：受限調色盤、粗像素、chiptune |
| 平台 | 待定（手機直向，或 PC） |

**世界：** 霧港（暫名），八十年代末。為了消化積壓案件，政府推行《司法效率條例》，今年是第二年。審判變快了，定罪率創新高，報紙稱之為「司法現代化」。舊區唐樓一棟接一棟被收購重建。

**主角（第七席）：** 四十二歲，喪偶，經營父親留下的當舖「信昌押」。舖頭在一棟舊唐樓的地舖，一家三代住在舖後的閣樓：九歲的女兒、年老的母親。整棟唐樓剛收到收樓信。

**基調：** 克制的社會寫實。系統是冷的，人是暖的。遊戲不會告訴你誰對。

**設計原則：被動式工作。** 主角不去找事件，事件自己走上門。白天是證人一個接一個上台，晚上是客人一個接一個走到櫃台前。兩邊共用同一套桌面操作（放大、對照）。玩法來自「一套每天會變的規則 × 可以替換的單位」，而不是逐分鐘撰寫的劇情。

## 2. 結構

```
序幕：收到陪審傳票 → 選出陪審團 → 宣誓
第 1–5 日：早晨 → 開庭 → 評議（暫議表決）→ 當舖 → 閣樓
          └ 任何一日有一方達五票 → 即日裁決 → 尾聲
第 5 日最終表決仍未有五票 → 延長評議（最多兩節）→ 無法裁決 → 尾聲
尾聲：報紙 + 主角的生活 + 夾萬裡沒被贖回的東西 +（提早結束時）「沒機會出庭的證人」
```

**早晨的報紙**是 Papers, Please 式的回饋：頭條會回應昨日的票數（「暫議 4:3，市民聚集法院外」）。翻到案件報道是輕微犯規，但可能有提示。

## 3. 開庭：Papers, Please 的窗口

**畫面：** 上半部是法庭（證人台、法官、控辯雙方、被告欄），下半部是你的桌面（筆記本、證物、規則簿、提問紙條）。手機直向時剛好上下分屏。證人一個接一個上台，就像入境者一個接一個走到窗口。

| 系統 | 規則 |
|---|---|
| **證詞流** | 證詞逐句以打字機效果出現，按固定速度自動推進，法庭不會等你。每一句都會留在「庭審記錄」裡，可以重看，但不能直接當卡用 |
| **釘選** | 點一下句子，把它釘進筆記本。每天 6 格；滿了就要拿走舊的才能釘新的 |
| **證物** | 呈堂時滑到桌面上，可以隨時拖動、放大。細節（時間、簽名、相片的角落）要放大才看得到 |
| **對照** | 選兩項（筆記 × 筆記、筆記 × 證物、證物 × 證物）。兩者合起來動搖控方某一環 → 疑點卡；鞏固某一環 → 佐證卡；無關 → 「好像不相關」，扣 1 精神。配對是預先設計的，就像 Papers, Please 的矛盾規則；扣精神是為了防止亂試 |
| **法官指引** | 規則簿的法庭那一頁，每天新增。指引可以把句子、證物或卡蓋上紅色「不予採納」 |
| **提問紙條** | 第二天起每日一張。根據一張卡寫問題交給法官：以呈堂證據為根據的問題通常獲准，證人的回答會帶出新的句子；以庭外資料為根據的問題會被拒絕，並記一次警告 |
| **精神** | 0–5 點，由前一晚幾點落閘、有沒有早睡決定。只有錯誤的對照會扣精神；精神歸零時你開始走神，證詞推進會變快 |

### 3.1 證人單位

法庭內容的標準單位，大約等於 Papers, Please 的一個入境者。一個案件，就是一串證人單位。

| 欄位 | 內容 | 例子：保安員鍾永發 |
|---|---|---|
| 身分 | 誰、哪一方傳召、第幾天出庭 | 福安樓保安員；控方；第 1 天 |
| 陳述 | 8–15 句，全部可以釘選；其中 2–4 句是「可對照的說法」 | 「我喺更亭睇緊電視」「燈光下面睇得好清楚」 |
| 證物 | 0–3 件，每件有 1–3 個要放大才看得到的細節 | 沒有 |
| 對照 | 說法 × 其他說法或證物 → 疑點或佐證；針對哪一環、強度多少 | 「睇緊電視」× 截電通知 → 疑點（在場） |
| 鉤子 | 會觸發的法官指引、提問紙條可以問的問題、評議室裡誰會引用他 | 羅先生會在評議室替他說話 |

## 4. 評議室：十二怒漢的桌子

**畫面：** 俯視的長桌，七個座位。每人面前有一顆石子：黑是有罪，白是無罪，灰是未決。桌子中央是控方的證據鏈（每個案件四至五個環），每個環上的裂痕反映整個房間對它的懷疑程度。

### 4.1 陪審員模型

每位 AI 陪審員由六個參數構成。**不寫死對白樹，而是讓參數決定他會被甚麼說服**：

| 參數 | 意思 | 範圍／例子 |
|---|---|---|
| 立場 | 傾向有罪或無罪 | −10（堅定無罪）至 +10（堅定有罪）；≥ +3 投有罪，≤ −3 投無罪，其餘投未決 |
| 在乎 | 對證據鏈每一環的重視程度 | 蘇太最在乎「動機」；馮 Sir 只在乎「物證」 |
| 吃哪一套 | 對四類論點的反應倍率：事實、程序、人情、權威 | 黃老闆吃「事實」裡的數字；主席吃「程序」 |
| 耐性 | 每天下降；越低越想「投完票回家」 | 黃老闆最低 |
| 從眾 | 每輪結束時，立場向多數一方漂移的幅度 | 主席低，蘇太高 |
| 秘密 | 特殊行為 | 內鬼幾乎不受說服，而且會說出庭上沒出現過的資料 |

**一張卡的效果** ≈ 卡的強度 × 他對那一環的「在乎」× 他對那類論點的「吃」× 你的信用。

玩家看不到數字，只看到他手上石子的顏色變化、頭像的表情和一句回應。

### 4.2 玩家的動作

每場評議有 3 次發言（信用高時多 1 次）：

| 動作 | 效果 |
|---|---|
| **出示** | 打出一張卡，針對某人的發言，或證據鏈的某一環 |
| **追問** | 要求某人解釋 → 揭示他手上的證據（變成你「借來的證據」），或逼出他論點裡的漏洞 |
| **引用指引** | 指出某句發言違反法官指引（引用了不予採納的證據、庭外資料、傳聞）。指得對，那個論點作廢、你的信用上升；指錯了，信用下跌 |
| **附和** | 支持某人的發言 → 放大他對其他人的影響，你和他的關係變好 |
| **要求重讀** | 請法庭重讀某句沒有釘選的證詞，把它變成卡（第三天起） |
| **提請表決** | 要求主席提早表決，當你認為現在的票數對你有利 |
| 沉默 | 不用發言次數；但一直沉默，大家會當你已經被說服 |

### 4.3 AI 的回合

每輪由一至兩位陪審員發言，最激動的先講。發言來自他自己的筆記和偏見，**可能包含錯誤**：記錯時間、引用已被剔除的證供、帶入庭外知識。這些錯誤本身就是可以對照的東西。**評議室也是一張 Papers, Please 的桌面。**

### 4.4 信用與耐性

| 數值 | 上升 | 下降 | 歸零時 |
|---|---|---|---|
| **你的信用** | 準確的卡、正確引用指引 | 無關或不予採納的卡、指錯、一直反對卻拿不出新論點 | 沒有人再聽你說 |
| **房間耐性** | 中場休息 | 每輪自然下降；激烈爭吵會加速 | 主席強制表決 |

### 4.5 暫議表決

- 每人把石子放進碗裡，逐顆揭曉。
- 任何一方達五票 → 即日裁決。
- 有陪審員被解除職務時（例如揭發內鬼）：剩六人仍需五票，剩五人須一致。少了一個對手，門檻卻變相提高了。
- 第五天的最終表決不設未決；立場為零的人跟隨多數。

## 5. 當舖：夜晚的櫃台

**畫面：** 從高櫃台後面往下看。上半部是櫃台外的客人：他比你矮，要伸手把東西遞上來。下半部是你的櫃面：物件、身份證、當票、警方失物通告、放大鏡、試金石。和法庭同一個分屏、同一套放大和對照操作。

**流程：** 開舖 → 客人逐個上門（每晚 3–4 個，其中一個是劇情客人）→ 落閘 → 閣樓。

### 5.1 客人單位

當舖內容的標準單位，和證人單位用同一套對照引擎。

| 欄位 | 內容 | 例子：第三晚的保安鍾永發 |
|---|---|---|
| 來意 | 押、賣或贖 | 押 |
| 物件 | 品類、牌子、成色、重量、序號；1–3 個要放大才看得到的細節 | 龍鳳金鐲；內圈的刻字被磨花了 |
| 說法 | 客人怎樣解釋物件的來歷 | 「呢隻鐲係我阿媽留低嘅」 |
| 證明 | 身份證、單據、當票 | 身份證 |
| 真相 | 正貨／假貨／賊贓／變相收買／劇情 | 鄺婆婆的遺物 |
| 對照 | 物件 × 失物通告、身份證 × 說法、物件 × 庭上的證物 | × 驗屍報告附上的生前照片 → 庭外線索 |
| 後果 | 收（壓價／公道／高價）、不收、報警 → 金錢、風險、他會不會回來 | 報警：你會成為證人，被解除陪審員職務 |

**生成客人：** 品類（手錶、金器、玉器、收音機、相機……）× 牌子 × 成色 × 真假 × 是否賊贓 × 外貌部件。每晚兩、三個生成客人，加一個劇情客人。

### 5.2 判斷

| 決定 | 結果 |
|---|---|
| 收：壓價 | 賺得多；客人記住了你 |
| 收：公道 | 賺得少；客人比較可能回來贖 |
| 收：高價 | 蝕錢；但有些人只差這一筆 |
| 不收 | 沒有收入，也沒有風險 |
| 報警 | 賊贓：小額獎金，但賊會記住你；與案件有關的物件：你可能會變成證人 |

收了賊贓，警察查舖時會被沒收並罰款，這是 Papers, Please 的警告和扣錢。

### 5.3 規例

當舖也有自己的規則，寫在規則簿的另一頁，每晚更新：驗身份證、未成年不收、金器要試金、每日的警方失物通告、火災後的「福安樓失竊財物」通告、金價變動。

### 5.4 押與贖

收當就開一張當票。客人可以在之後的晚上回來贖，你收回本金和利息。審判結束時還沒贖回的東西，會留在你的夾萬裡，出現在尾聲。

### 5.5 外界的入口

陪審員不准調查，但櫃台會把整個世界帶到你面前：

- **案件的話題：** 客人一開口講案件，你要選 **制止**（守規則）或 **聽下去**（得到庭外線索，風險和偏見一起上升）。
- **變相收買：** 陌生人用五千元買走櫃面一部壞收音機，「做生意啫」。
- **恐嚇：** 客人押一隻廉價手錶，臨走時說出你女兒讀哪間學校。
- **案件的物件：** 死者的遺物、被告家人的首飾，會自己走上櫃台。

**庭外線索不能當證據，但可以當地圖。** 它不能在評議室公開出示（那是犯規），但會告訴你明天提問紙條該問甚麼、該追問誰、哪件證物要放大看。

### 5.6 閣樓

落閘之後回到舖後的閣樓，這是 Papers, Please 式的一頁：交租、母親的藥、女兒的狀態、信件。然後選一件事：陪家人、整理筆記（不限時地做一次對照）、私下調查（犯規），或者早睡。

| 資源 | 說明 |
|---|---|
| 金錢 | 陪審津貼不夠開支；第三晚要交租 |
| 精神 | 越晚落閘，明天越少；早睡可以補回一點 |
| 家人 | 女兒在櫃台邊做功課，母親在閣樓等你落閘；長期忽略會觸發家庭事件 |
| 風險（隱藏） | 犯規被發現的機會；只會以徵兆出現（舖外有人影、記者叫得出你的名字） |
| 良知（隱藏） | 只影響尾聲 |

## 6. 七席與視角

### 6.1 一局之內：「你手上的證據」是不對稱的

每位陪審員在庭上注意到的東西都不同。你只有自己釘下的；其他人的證據，要在評議室「追問」才會浮現。這就是「一開始只能從主角出發」的機制化：**視角先是限制，然後才一步步打開。**

### 6.2 跨周目：七席就是七條路線

法庭內容（證詞、證物）全部共用；每一席換掉的是 **眼睛、櫃台、秘密**。每一席的夜晚都按同一原則設計：一個櫃台，客人自己走上門。換的只是貨品表和劇情客人，引擎不變。

| 席 | 人物 | 獨有的「眼睛」（桌面能力） | 夜晚的櫃台 | 解鎖（建議） |
|---|---|---|---|---|
| 1 | 主席 梁守仁 | 決定表決的時機 | 街坊會：替人代填表格 | 達成「無法裁決」 |
| 2 | 黃大有 | 單據上的價錢、份量一眼看出 | 自己茶餐廳的收銀處 | 達成「速判無罪」 |
| 3 | 羅永昌（內鬼） | 知道發展商的劇本；勝利條件相反 | 貨倉夜更：核對送貨單 | 揭發內鬼，或收下那五千元 |
| 4 | 林曉晴 | 看得懂證物上的英文附註 | 報攤兼職：被禁止看的新聞就在手邊 | 發現被告隱瞞的事 |
| 5 | 蘇美玲 | 看得出證人說謊時的小動作 | 丈夫的士多 | 達成「罪成」 |
| 6 | 馮國強 | 放大火場相片時看得到燒痕的方向 | 另一棟大廈的看更 | 第二起火點成立 |
| 7 | 你（當舖朝奉） | 識貨：金器、手錶、序號類的對照更容易 | 信昌押 | 預設 |

### 6.3 知識就是進度

在內鬼的路線知道了保安是誰的人，回到第七席時，你的角色並不知道。你不能直接說出來，但你知道今晚該留意誰、明天該問甚麼。這是 *Outer Wilds*、*Return of the Obra Dinn* 式的知識型進度：**角色歸零，玩家沒有。**

## 7. 結局架構

- 結局 = 四條軸的組合（見 [01 §7](01-core-loop.md#7-多結局從哪裡來)），加上尾聲：報紙、主角的生活、夾萬裡沒被贖回的東西。
- 目標：第一周目（第七席）約 10 個可見結局；全部路線 20 個以上，另設一個需要多席知識的真結局。
- 原則：**沒有「正確結局」**，只有你付了甚麼、換到甚麼、錯過了甚麼。

## 8. 美術與音效

| 項目 | 方向 |
|---|---|
| 解像度 | 直向 216×384／橫向 384×216，都可以整數放大到 1080p（×5） |
| 調色盤 | NES 風格；每個場景不多於 16 色；紅色只留給「不予採納」和犯規 |
| 字型 | 12px 繁中像素字。候選：Fusion Pixel Font（12px 繁中版）、Cubic 11（俐方體 11 號）。授權要逐一核對，Cubic 11 的授權來源說法不一 |
| 場景 | 法庭（橫切面）、評議室（俯視長桌）、當舖（從高櫃台後往下看）、閣樓 |
| 介面母題 | 圖釘（筆記）、紅色印章（不予採納）、黑白石（投票）、會裂開的鎖鏈（證據鏈）、當票、門口的屏風、蝙蝠銜錢的招牌 |
| 人物 | 評議室頭像 32×32；對話特寫 64×64，每人三種表情 |
| 音樂 | 2A03 式 chiptune（兩個方波、三角波、噪音） |
| 音效 | 每個角色的文字嗶聲音高不同；庭上的時鐘滴答；石子落碗；落閘；深夜的雨 |

## 9. 製作建議

- **技術：** 舊 repo 的 Phaser 3 + TypeScript + Vite + Capacitor（iOS）骨架仍在 main 的歷史裡（`53ab3d3`），可以取回再用；分支劇情可以用 inkjs（Ink 的 JS 版）。若 PC 優先，Godot 4 + Ink 也合適。
- **模擬與表現分開：** 陪審員模型、投票、對照判定寫成純邏輯，不依賴遊戲框架。這樣可以用腳本跑上千場模擬評議來調整平衡，例如確保第一天你的票真的是第五票。
- **案件就是資料：** 一個案件等於五張表：證人單位（台詞）、證物（包括可放大的細節）、對照配對、法官指引、陪審員參數。當舖再加兩張：貨品（生成用）和劇情客人。寫劇本的人填表，程式不用改。
- **一套引擎，兩張桌面：** 法庭和當舖共用放大、對照、規則簿；當舖只多了開價和試金兩個動作。
- **分期：**

| 階段 | 內容 | 目的 |
|---|---|---|
| 0 原型 | 第一、二天；純文字；6 個 AI 陪審員；不做當舖 | 回答 [01 §9](01-core-loop.md#9-最小原型) 的四個問題 |
| 1 垂直切片 | 第七席完整一周目：五日、當舖、約 10 個結局、像素美術初版 | 證明一局的完整體驗 |
| 2 完整版 | 再加 2–3 席路線（建議：馮國強、羅永昌、林曉晴） | 多周目的價值 |
| 3 擴展 | 七席全開，加真結局 | |

- **若上手機：** 第一天本身就是最強的試玩，「一票之重」十多分鐘內就出現。可以免費開放第一天，再一次性解鎖完整審判（沿用舊 repo 的 RevenueCat 思路）。

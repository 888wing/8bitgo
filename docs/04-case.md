# 04 範例案件：福安樓縱火案

> 用途：驗證核心。人物、地點、細節都可以替換；格式見 [05 §2](05-production.md#2-內容格式)。對白暫以粵語口語示意。
>
> 五天的資料寫在 `prototype/case.js`（第三至五天是初稿）。寫成資料時加了提問紙條、夜晚的選項和結局的觸發條件，見 [決策 17–21](decisions.md)。

## 1. 案情

1987 年 11 月一個雨夜，凌晨 2:10，霧港西區唐樓「福安樓」起火，三人死亡：獨居的鄺婆婆（81 歲），以及四樓的周太和她六歲的女兒。

被告 **何嘉樂**（22 歲），外賣員，住四樓，帶頭反對業主「昇平置業」收樓。控方指他因收樓糾紛縱火洩憤，控以謀殺罪。

## 2. 證據鏈與表決規則

| 環 | 控方說法 | 必要？ |
|---|---|---|
| 在場 | 凌晨兩點，被告在樓梯 | 必要 |
| 起火 | 致命的那把火是他點的 | 必要 |
| 手段 | 他買了火水 | 輔助 |
| 動機 | 收樓糾紛，他揚言放火 | 輔助 |
| 口供 | 他承認點火 | 輔助；第 3 天被剔除 |

- 一個環在某人心中成不成立，看他對支持這個環的說法：信的多於疑的，就成立；疑的多，就存疑。
- **一般陪審員：** 在場或起火任何一個存疑，投無罪；兩個都成立，再加至少一個輔助的環，投有罪；其餘投未決。
- **偏見會改寫規則：** 例如黃老闆只要「動機」加「在場」就投有罪。

## 3. 五天的證人

### 第 1 天：控方開案（你就是第五票）

- **偵緝督察鄭志雄**（控方）
  - ① 起火點在三樓樓梯（支持起火）
  - ② 打火機在起火點找到，刻著「樂」字（支持起火）
  - ③ 被告自願簽署口供（支持口供）
  - 證物：P1 樓梯相片（角落拍到地下寫字樓的門）、P2 打火機、P4 口供（頁底有手寫附註）
- **保安鍾永發**（控方）
  - ① 兩點見到被告在樓梯（支持在場）
  - ② 當時在更亭看電視（他的可信度）
  - ③ 燈光下看得好清楚（支持在場）

### 第 2 天：動機與手段（辯方突然呈上截電通知）

- **業主代理人屈家輝**（控方）
  - ① 被告揚言「一把火燒咗佢」（支持動機）
  - ② 拉扯時，被告的東西跌滿地（看似無關）
  - 盤問時，辯方呈上 D1：電力公司的截電通知，業主九日前要求截斷全幢電源
- **五金舖老闆**（控方）
  - ① 案發當日下午，被告買了兩公升火水（支持手段）
- 法官指引：傳聞證據不可作為事實依據。一個街坊轉述鄺婆婆的話被剔除，你要親手蓋上「不予採納」，先熟習這個動作。

### 第 3 天：口供爭議（你要親手抹去口供）

- 開庭時，法官裁定口供在不當情況下取得，不可接納。你翻到督察③和口供那一頁，蓋上紅色「不予採納」。「口供」這一環從黑板上被擦掉。
- **法醫文醫生**（控方）
  - ① 死者吸入濃煙致死，時間約 2:15 至 2:30（支持在場）
  - ② 鄺婆婆房內有一個火水暖爐（看似無關）
  - ③ 她手腕有長年戴鐲的壓痕，現場卻找不到手鐲（看似無關）
  - 證物：P5 驗屍報告，附死者生前照片

### 第 4 天：視察現場與火場證據（陪審團到福安樓）

- **現場視察：** 早上，陪審團由法官和庭警帶到福安樓。保安站在樓梯口看著你們。不能碰任何東西，但可以看：地下寫字樓門口有一道燒痕。
- **消防調查主任區志輝**（控方）
  - ① 只有一個起火點（支持起火）
  - ② 助燃劑是火水（支持手段）
  - 證物：P6 火場相片組
- **被告友人李志健**（辯方）
  - ① 被告那個星期一直在找他的打火機
  - ② 案發當晚，被告一點四十才離開他家

### 第 5 天：被告作供（再沒有未決可以躲）

- **被告何嘉樂**（辯方）
  - ① 火水是買給鄺婆婆的暖爐用的
  - ② 打火機早就不見了
  - ③ 他返到大廈就即刻上樓
  - 盤問時，控方呈上 P7：他當晚的衣物，袖口有煙灰，口袋有一張燒焦的傳單
- 結案陳詞；法官總結：謀殺罪的元素，以及可以考慮的較輕替代罪名（縱火）。

## 7. 三層真相

玩家永遠不會被直接告知「答案」，只會在結局看見後果。

這是作者的背景設定，畫面上不會證實，也不必全部推得出來：玩家判斷的是證據能否證明控罪，不是追查真相（[決策 22](decisions.md)）。

| 層 | 內容 | 怎樣得到 |
|---|---|---|
| 表層 | 何嘉樂縱火洩憤，燒死三人 | 控方的故事 |
| 第一層 | 業主截斷了全幢電源，火水是給鄺婆婆的暖爐用的；樓梯沒有燈，保安卻說看得清楚，又說在看電視；打火機案發前一星期已經不見了；口供是在三十小時不准睡的情況下取得的 | 庭上的理由，足以構成合理懷疑 |
| 第二層 | 有兩個起火點：地下寫字樓門口有一處更早、更小的燒痕 | 視察現場加提問紙條 |
| 第三層 | 地下那把小火是何嘉樂點的：他把收樓信塞進寫字樓門縫點火洩憤，以為火已經熄了。致命的樓梯大火，是保安受發展商指使放的；他還趁亂拿走了鄺婆婆的龍鳳金鐲。口供不全是假的，他承認的是「地下那把火」 | 第五天的證物可以推斷出一半；另一半要靠當舖的那一晚、犯規，或其他席位的路線 |

**道德結：** 裁定謀殺罪不成立，一個真的放過火的人會走出法庭；裁定罪成，真正的兇手永遠不會被追究。

## 8. 結局（第七席，部分）

| 結局 | 觸發 | 尾聲 |
|---|---|---|
| 一日審判 | 第一天第五票有罪 | 排期表上，餘下六個證人的名字被逐一劃掉。三年後福安樓變成豪宅，你的唐樓是下一棟 |
| 罪成 | 第二至五天五票有罪 | 被告終身監禁。如果你不信保安卻投了有罪，尾聲會翻開你的筆記本，停在那一頁 |
| 速判無罪 | 第三天或之前五票無罪 | 被告獲釋，輿論譁然；保安從未被追問 |
| 合理懷疑 | 第四、五天五票無罪 | 被告獲釋；第二起火點只在報紙角落出現過一次 |
| 替代裁決 | 第五天：第二起火點和地下那把火都成立 | 謀殺罪不成立，縱火罪成立；保安被傳召協助調查 |
| 無法裁決 | 延長評議後仍無五票 | 重審；新的陪審團一日審結 |
| 被解除職務 | 犯規被發現，或申報利益 | 你坐在法庭外的長椅上；報紙上的票數只有六張 |
| 交出金鐲 | 第三晚報警 | 你成為證人，審判沒有你也繼續。保安有沒有被追查，要看你之前在評議室留下了甚麼 |
| 審訊無效 | 舉報收買後，法官解散陪審團 | 審判重來；收買調查開始，但沒有人知道會查到多深 |
| 收下五千元 | 收錢並投有罪 | 你交到租了。第二年，你的唐樓還是被收了 |
| 真結局 | 需要其他席位的知識 | （保留） |

每個尾聲都會打開當舖的夾萬：何太的玉鐲有沒有被贖回，那隻金鐲還在不在。

## 9. 這個案件怎樣測試核心

- **一票之重：** 第一天四人傾向有罪，你的票就是第五票。
- **改印章：** 第二天的截電通知，會令玩家翻回第一天，劃掉自己對保安的印章（理由 3、4）。
- **規則 vs 真相：** 理由 1 指向真相，第三天卻被剔除；合法的路要繞經理由 7。
- **眼睛：** 理由 2 只有當舖朝奉看得到。
- **不一面倒：** 理由 8、9 對被告不利。
- **評議室也是桌面：** 內鬼的失言（理由 10）只能在評議室裡發現。
- **夜晚是對白天的考試：** 第三天沒有留意驗屍報告的人，第三晚認不出那隻金鐲（理由 11）。

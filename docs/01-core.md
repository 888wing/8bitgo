# 01 核心

> 一個動作、一個循環、一個代價，其餘全部為這三樣服務。
> 篩選規則：每個系統都要回答「它令蓋章更難，還是更重？」兩樣都不是，就不做。

## 1. 動作：蓋章

證人的說法，就是 Papers, Please 的入境者。

- 每個證人有 **兩、三個關鍵說法**。他講到時，主角會把它抄進筆記本（手寫動畫），所以不需要另外標示哪句重要。
- 證人走下證人台前，印章盤滑出，你為每個說法蓋章：**「信」** 或 **「疑」**。可以留空，留空就是未決。
- **對照**是替印章找理由的工具：把證物拖到筆記上的某個說法，或把兩個說法連起來。配對是預先設計的；配得上，主角會在旁邊寫一行批註，例如「截咗電，點睇電視？」。配不上，甚麼都不會發生。
- 新證據出現時，可以翻回前面的頁數改印章。舊的印章會被劃掉，新的蓋在旁邊：**筆記本記住你怎樣改變主意。**
- **法官指引就是規則：** 法官下令剔除某個說法時，你要親手拿紅色印章，在那一行蓋上「不予採納」。

## 2. 評議室：黑板

- 主席把當天的關鍵說法、加上仍有爭議的舊說法，用粉筆寫上黑板，然後逐個問大家的看法。每個人表態時，主席在他的座號下畫記號。**黑板就是七個人的印章表。** 一開始只有你那一欄是滿的，其他人的要等他們開口。
- 你的筆記本是私人的，黑板是公開的，兩者可以不一樣，別人也一樣。
- **每個人的票由他相信甚麼決定：** 控方證據鏈裡任何一個 **必要的環**，只要他存疑，他就投無罪。「合理懷疑」變成看得見的規則。
- 一個證人被指出說了兩次謊，聽的人連他其餘的說法也不再相信。
- **你的動作**（每場大約三次，由牆上的鐘決定：每個動作分針走一格，到四點半庭警敲門）：

| 動作 | 做法 |
|---|---|
| 出示理由 | 把筆記上的批註或證物推到某人面前，針對黑板上的某一格 |
| 指出違規 | 翻開《陪審員須知》：他在用被剔除的說法，或庭外聽回來的東西 |
| 追問 | 問某人對某一格的看法，揭開他的記號和理由 |
| 提請表決 | 請主席現在就表決 |

- 別人也會出示理由，可能是你沒發現的；他們用過的理由，你之後也可以用。
- 每個陪審員都有幾格「翻不動」（偏見），只有特定的理由才撬得開；有人見到多數人站在一邊就會跟大隊；有人一直看錶。

## 3. 表決：五票即決

- 《司法效率條例》（虛構）：每天休庭後暫議表決，有罪、無罪或未決；**任何一方達五票，即日裁決，審判終止；還沒出庭的證人永遠不會出庭。** 每日票數向公眾公佈。
- 七人、最少五票成裁決，是香港現行陪審團的規模；人數減至六人仍需五票，減至五人須一致（見[社區法網](https://clic.org.hk/zh/topics/policeAndCrime/court_procedure/jury/majority_verdicts)）。「每天表決、即日結案」是虛構的部分。
- **不記名投票：** 每人在紙條上寫，摺好，放進木箱；主席逐張讀出，在黑板上畫「正」字。有人會講一套、投一套。
- 第五天的最終表決不設未決。

## 4. 代價：信與投之間的距離

- 你的票是自由的，可以和自己的印章相反。
- 遊戲記住兩樣東西：你相信甚麼（印章），你做了甚麼（票）。兩者的距離是一條結局軸，也是 Papers, Please 共犯感最直接的版本：**最容易的路，是投一張你自己也不信的票，然後回家。**
- 每天結束有一頁：當舖今天沒做成的生意、家人、一件事。撐多一天，就多付一天。

## 5. 視角：職業就是眼睛

- 同一件證物，不同的人看得到不同的東西。每一席都有幾個 **只有他做得到的對照**。
- 主角是當舖朝奉，他識貨：用放大鏡看那個打火機，看得到火石磨平了、棉芯是乾的，這個打火機根本打不著火。
- 換一席，就換一雙眼睛、一欄初始印章、一個秘密；證人和證詞全部共用。

## 6. 刻意不做的東西

數值條、分數、「答對了」、卡牌、陪審員參數面板、第二個 loop、生成內容。它們都會令蓋章變輕。

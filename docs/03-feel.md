# 03 質感：怎樣避免廉價感

> 廉價感通常來自三件事：介面像試算表、遊戲替你判對錯、每一天都一模一樣。下面每一條，都針對其中一件。

## 1. 介面

1. **一切都在世界裡。** 筆記本、印章、黑板、牆上的鐘、選票、報紙、當簿。規則：1987 年的法院裡找不到的東西，不上畫面。沒有數值條，沒有分數，沒有彈出視窗。
2. **黑板代替表格。** 七個人的印章表，是主席用粉筆寫的；有人改變主意，他會擦掉重寫。
3. **不打分、不判對錯。** 沒有「答對了」；對照配不上時，也不會有「錯誤」。回饋只來自人：一個陪審員停了半秒、主席擦掉一個記號、被告抬頭望你。遊戲在任何時候都不會告訴你真相。
4. **教學就是《陪審員須知》。** 法官開庭時對陪審團的訓示、庭警遞給你的小冊子，就是全部教學。第一個證人很短，讓你邊做邊學。
5. **選項不標善惡。** 選項是主角會說的話，旁邊沒有「良知 +1」。

## 2. 手感與聲音

6. **動作少，但每個都做到最好。** 全遊戲只有五個主要動作：蓋章、放大、對照、在評議室出示、投票。每個都要有重量：印章落下時墨水滲開、畫面輕微一震、一下悶響，而且每一下的位置和缺墨都略有不同。
7. **聲音是一半的質感。** 蓋章、翻紙、粉筆、吊扇、窗外的雨、牆上的鐘、法槌。音樂只在幾個地方出現；主席讀選票時，只剩下鐘聲。
8. **每個角色有自己的說話節奏。** 文字速度和嗶聲音高因人而異：督察講得快而平，保安常常停頓，主席每句都慢半拍。

## 3. 演出與節奏

9. **演出靠節奏，不靠字數。** 每個對白框不超過兩行；重要的一句之前留一拍空白；人物有小動作（抹汗、看錶、望向被告）；特寫頭像只留給關鍵的句子。
10. **每天都有一件打破常規的事。** 流程每天一樣，事件每天不同（見 [02 §4](02-flow.md#4-五天的節奏)）。有重複，也有破格，才有節奏。
11. **筆記本會記住你。** 改過的印章留著劃線。到最後，這本筆記就是你這一星期的懷疑，也是尾聲會翻開的東西。
12. **結局是場景，不是文字頁。** 宣讀裁決、報紙頭版、幾年後的一幕、當舖夾萬裡沒被贖回的東西。

## 4. 世界與角色

13. **具體的細節。** 吊扇、陪審團室的煙灰缸和茶杯、法院門外的記者、電車的叮叮聲、當舖門口的屏風、蝙蝠銜錢的招牌。具體，才像有人認真做過。
14. **角色是人，不是數值。** 每個陪審員有一個習慣（主席抹眼鏡、黃老闆看錶）、一個轉變、一個軟弱的時刻。玩家永遠看不到他們的參數。

## 5. 美術

15. **一致、克制。** 一個解像度、一張 32 色的調色盤、一套印刷字（另加只在筆記本用的手寫字）、整數放大、沒有漸變和發光。紅色只表示兩件事：你親手找出的矛盾，和「不予採納」。保持一致，是令像素美術不顯得廉價最省錢的方法。細節見 [06 美術規範](06-art.md)。
16. **只做五個地方，每個都做好。** 法庭、評議室、當舖閣樓、早晨的街、案發現場。

| 項目 | 方向 |
|---|---|
| 解像度 | 橫向 480×270，整數放大（全螢幕 1080p 剛好 ×4）；手機橫放，直向版面未定 |
| 調色盤 | 全遊戲 32 色，NES 風格但偏灰：法庭是日光燈的青綠，評議室是煙黃，夜晚是雨的藍 |
| 字型 | 對白 13px、筆記本 12px 手寫，8px 細字要用放大鏡；正式版的像素字候選 Fusion Pixel Font、Cubic 11，授權要逐一核對 |
| 人物 | 評議室頭像 32×32；特寫 56×60，每人三種表情 |
| 音樂 | 2A03 式 chiptune，用得很省 |

## 參考

| 作品 | 學它甚麼 |
|---|---|
| *Papers, Please* | 桌面的實物感、印章、灰暗而克制的色調 |
| *Return of the Obra Dinn* | 筆記本就是介面；不即時判對錯 |
| *VA-11 Hall-A* | 被動式工作（調酒）也可以靠角色、音樂和文字做出質感 |
| *Pentiment* | 真相永遠不被確認；字的樣子本身就在說故事 |
| 《十二怒漢》（1957） | 一個房間、一張桌子，也可以有張力 |

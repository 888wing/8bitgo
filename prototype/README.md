# 第七席原型

這裡是文字原型，以及案件資料和規則的 JS 版。文字原型只玩第一、二天；`case.js` 也寫了第三至五天，由 Godot 版用。完整一局在 [game/](../game/README.md)（Godot 4.7）；網頁版的桌面切片（Phaser）最後一版在 commit `3a3a819`。

規則從第三天起只在 Godot 版（`game/scripts/rules/rules.gd`）；這裡的 `engine.js` 不再加新規則。

先在這個資料夾執行 `node build.js`，產生 `dist/index.html`，然後雙擊就可以玩。開發時要經伺服器載入 ES 模組：執行 `python3 -m http.server 8000`，打開 http://localhost:8000 。

## 共用的檔案

| 檔案 | 內容 |
|---|---|
| `case.js` | 案件資料：證人、說法、證物、理由、陪審員、對白。改內容只需要改這裡；改完在 repo 根目錄執行 `npm run case`，Godot 版才讀得到 |
| `engine.js` | 規則：蓋章、對照、黑板、說服、跟大隊、表決。不碰畫面。Godot 版的 `game/scripts/rules/rules.gd` 由它移植 |
| `test/` | 規則和內容的測試：`npm test` |
| `sim.js` | 平衡模擬：`npm run sim` |
| `build.js` | 把文字原型打包成單一檔案 |

## 文字原型

純文字，用來回答 [05 §1](../docs/05-production.md#1-原型先驗證核心) 的四個問題。沒有美術和音效；所有數值都是起始值。畫面在 `main.js` 和 `index.html`。

一局約二十分鐘：序幕；第一天（督察、看更）；第二天（代理人、五金舖東主）。每天休庭後評議，然後表決。

設定裡有兩個選項：

- **證詞自動推進：** 試另一種法庭節奏。
- **顯示陪審員的底牌（測試用）：** 黑板上會顯示每個人還沒說出口的印章，以及他現在會怎樣投票。

### 平衡模擬

`npm run sim` 用五種假玩家，各跑 5000 局：

| 玩家 | 結局 |
|---|---|
| 跟大隊：全信，投有罪 | 第一天罪成 100% |
| 憑印章：隨意存疑，按筆記投票 | 未有裁決 91%、第一天罪成 7%、第二天罪成 2% |
| 細心：找到大部分理由，說服得法，按筆記投票 | 第二天無罪 92%、未有裁決 8% |
| 拉住天秤：說服得法，但一直投未決 | 未有裁決 100% |
| 隨機 | 未有裁決 45%、第一天罪成 33%、第二天罪成 22% |

兩個發現：

- 第一天表決前，六個 AI 裡有四人投有罪。只要你投有罪，審判就在第一天結束。
- 說服得法的玩家，第二天會令四個 AI 傾向無罪，自己變成第五張無罪票。這時要決定：當日結案，還是拉住天秤，等第三天的證人。

### 已知的限制

- 只有第一、二天；夜晚只有一頁文字。
- 陪審員的反應是預先寫好的：同一個理由推到同一個人面前，反應每次都一樣。
- 第一天沒有真正違規的發言，在那天「指出違規」只會浪費一次發言。

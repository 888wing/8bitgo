# 第七席原型

兩個原型，用同一份案件資料和同一套規則：

| 原型 | 試甚麼 | 打開 |
|---|---|---|
| [文字原型](#文字原型) | 核心規則：蓋章、評議、表決（第一、二天） | `dist/index.html` |
| [桌面手感切片](#桌面手感切片) | 像素畫面的手感：拖證物、放大鏡、對照、蓋章（第一天的法庭） | `dist/desk.html`，要連網 |

先在這個資料夾執行 `node build.js`，產生 `dist/` 裡的兩個檔案，然後雙擊就可以玩。開發時要經伺服器載入 ES 模組：執行 `python3 -m http.server 8000`，文字原型在 http://localhost:8000 ，桌面在 http://localhost:8000/desk/ 。

## 共用的檔案

| 檔案 | 內容 |
|---|---|
| `case.js` | 案件資料：證人、說法、證物、理由、陪審員、對白。改內容只需要改這裡 |
| `engine.js` | 規則：蓋章、對照、黑板、說服、跟大隊、表決。不碰畫面 |
| `test/` | 規則和內容的測試：`npm test` |
| `sim.js` | 平衡模擬：`npm run sim` |
| `build.js` | 把兩個原型各自打包成單一檔案 |

## 文字原型

純文字，用來回答 [05 §1](../docs/05-production.md#1-原型先驗證核心) 的四個問題。沒有美術和音效；所有數值都是起始值。畫面在 `main.js` 和 `index.html`。

一局約二十分鐘：序幕；第一天（督察、看更）；第二天（代理人、五金舖東主）。每天休庭後評議，然後表決。

設定裡有兩個選項：

- **證詞自動推進：** 試另一種法庭節奏。
- **顯示陪審員的底牌（測試用）：** 黑板上會顯示每個人還沒說出口的印章，以及他現在會怎樣投票。

### 平衡模擬

`npm run sim` 用五種假玩家，各跑 5000 局：

| 玩家 | 結局 |
|---|---|
| 跟大隊：全信，投有罪 | 第一天罪成 100% |
| 憑印章：隨意存疑，按筆記投票 | 未有裁決 91%、第一天罪成 7%、第二天罪成 2% |
| 細心：找到大部分理由，說服得法，按筆記投票 | 第二天無罪 92%、未有裁決 8% |
| 拉住天秤：說服得法，但一直投未決 | 未有裁決 100% |
| 隨機 | 未有裁決 45%、第一天罪成 33%、第二天罪成 22% |

兩個發現：

- 第一天表決前，六個 AI 裡有四人投有罪。只要你投有罪，審判就在第一天結束。
- 說服得法的玩家，第二天會令四個 AI 傾向無罪，自己變成第五張無罪票。這時要決定：當日結案，還是拉住天秤，等第三天的證人。

### 已知的限制

- 只有第一、二天；夜晚只有一頁文字。
- 陪審員的反應是預先寫好的：同一個理由推到同一個人面前，反應每次都一樣。
- 第一天沒有真正違規的發言，在那天「指出違規」只會浪費一次發言。

## 桌面手感切片

第一天的法庭桌面：鄭督察和鍾永發兩個證人，480×270，美術全部是程式畫的佔位圖。只試四種手感：拖證物、放大鏡、對照拉紅線、蓋章。規格見 [06 美術規範](../docs/06-art.md)。玩一次約十分鐘。

### 怎樣玩

- 點左下角的對白框，或按空白鍵，聽下一句。
- 證物會送到右上角的托盤：拖到桌上，或者點一下。
- 拖動放大鏡，在證物上慢慢移動。
- 按「對照」，點一個說法，再點證物上的一個細節。
- 證人退庭前，把印章拖到每個說法上，然後按印章盤上的「退庭」。
- 「須知」是《陪審員須知》；◀ ▶ 翻筆記本；右上角的喇叭或 M 鍵靜音。

完結頁有五個問題，請試玩的人回答，然後按「再玩一次」。

### 檔案

| 檔案 | 內容 |
|---|---|
| `desk/main.js` | 入口：載入字型，按整數倍放大，開 Phaser |
| `desk/court.js` | 法庭場景：對白、筆記本、證物、放大鏡、對照、蓋章 |
| `desk/art.js` | 調色盤和全部佔位美術。換正式美術時，按這裡的名字和尺寸逐張換 |
| `desk/pixels.js` | 畫點、畫線、網點，以及把網頁字型壓成點陣字 |
| `desk/layout.js` | 版面上每一樣東西的位置和大小 |
| `desk/sound.js` | 即場合成的音效 |
| `desk/index.html` | 外框 |

### 已知的限制

- 只有第一天的兩個證人；沒有評議室和表決（文字原型有）。
- 美術和音效都是佔位的；沒有環境聲和音樂。
- 要連網：Phaser 和字型都從網上載入。字型載入失敗時會改用系統字型，樣子會不同。
- 證物、放大鏡和印章只可以用滑鼠或手指操作；鍵盤只可以聽下一句（空白鍵、Enter）、退出對照（Esc）和靜音（M）。
- 手機要橫放；直放時畫面很小。

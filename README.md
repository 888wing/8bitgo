# 第七席 The Seventh Seat（暫名）

**法庭版 *Papers, Please*。** 一款 8-bit、劇情主導、多結局的裁決模擬遊戲。你是七人陪審團的第七席。

> 你永遠不會知道真相。你只能決定相信誰。

霧港（虛構）實施《司法效率條例》的第二年：陪審團每天休庭後都要表決，**任何一方夠五票，審判即時結束。** 第一天評議，已經有四個人認定被告有罪。你那一票，決定這場審判有沒有第二天。

## 核心

- **一個動作：** 證人走下證人台前，你為他的每個說法蓋章：「信」或「疑」。
- **一個循環：** 證人上台，你對照證物、蓋章；評議室裡，主席把七個人的看法寫上黑板，你用理由改變別人的想法；然後不記名表決，夠五票就結案，否則明天繼續。
- **一個代價：** 你可以投一張和自己印章相反的票，好讓大家早點回家。遊戲會記住。

## 設計支柱

1. **一票之重：** 每一天，你的票都可能終結審判。
2. **你只知道你看見的：** 你的職業決定你看得到甚麼；別人怎樣想，要到評議室才揭開。
3. **懷疑有代價：** 撐住要付出；放手，只需要投一張和自己判斷相反的票。

每個系統都要過一關：**它令蓋章更難，還是更重？兩樣都不是，就不做。**

# 第七席 The Seventh Seat（暫名）

**法庭版 *Papers, Please*。** 一款 8-bit、劇情主導、多結局的裁決模擬遊戲。你是七人陪審團的其中一席。

> 霧港實施《司法效率條例》的第二年：陪審團每天休庭後都要表決，**任何一方夠五票，審判即時結束。**
> 第一天評議，已經有四個人認定被告有罪。
> 你那一票，決定這場審判有沒有第二天。

## 核心提案

驅動 core loop 的元素是 **懷疑**：在法庭賺，在評議室花，在夜裡付代價。
「五票即決」令它每天都有生死。**真相需要時間，時間需要懷疑。**

推論過程和其他候選方案，見 [docs/01-core-loop.md](docs/01-core-loop.md)。

## 設計支柱

1. **一票之重**：每一天，你的票都可能終結或延續審判。
2. **你只知道你看見的**：一開始只能從主角出發，用自己手上的證據判斷；其他人的證據要在評議室裡慢慢浮現。
3. **懷疑有代價**：撐住疑點，要用生計、家人、人情和安全去付。
4. **程序與真相不一定同路**：守規矩的人未必找到真相，找到真相的人可能已經犯規。
